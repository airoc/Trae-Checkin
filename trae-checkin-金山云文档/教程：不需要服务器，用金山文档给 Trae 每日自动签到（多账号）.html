不需要服务器，用金山文档给 Trae 每日自动签到（多账号）

零基础照着做就行，全程大概 10 分钟。配好一次，以后每天全自动，不用再打开电脑。

一、这是干什么的

Trae CN是一款 AI 编程工具，每天签到能领积分（可以换模型的用量）。

这个方案用「金山文档」的定时脚本帮你自动签到，好处是：

  • 不用自己买服务器，也不用电脑一直开机；
  • 到点由金山文档云端自动跑；
  • 支持多个账号；
  • 签完能推消息到微信（Server酱 / PushPlus）或企业微信。

整体就三步：拿 token → 建表格填进去 → 粘脚本设定时任务。下面一步步来。

二、开始前要准备的

一共三样，都很容易凑齐：

  1. 一台 Windows 电脑，并且已经安装、登录过 Trae 客户端（用于获取真实的设备ID）；
  2. 这台电脑装了 Python（能运行 .py 脚本即可）；
  3. 一个金山文档账号（微信扫码登录小程序即可）。

三、第一步：拿到你的 token

「token」可以理解成你的登录凭证——脚本靠它才能代替你去签到。这个不用自己找，脚本会自动取。

1. 运行取 token 的脚本

进入放脚本的文件夹（把下面路径替换成你自己的），然后运行：

python trae_gettoken.py

运行后：

  1. 终端会打印你的设备号；

  2. 自动在默认浏览器打开登录页（没弹出来就手动把终端里那条链接复制到浏览器）；

  3. 在网页上用手机号 + 验证码登录，然后点「登录并使用 Trae」；

  4. 登录成功后，浏览器地址栏会跳到 http://127.0.0.1:xxxxx/authorize?refreshToken=...（页面显示「无法访问」是正常的，看地址栏、别看页面）；

  5. 把地址栏这一整条链接复制下来，粘回终端，回车。

2. 拿到一行 JSON

做完上面，终端会打印类似这样的一行：

{"name":"你的名字","refreshToken":"eyJhbGciOi...很长一串","deviceId":"3124143766407755"}

这一整行就是你的账号信息，先复制存好，下一步要用。它也会自动写进同目录的 tokens.txt 里，找不到了去那里看。

提示：如果是多账号，重复本步骤，每个账号各跑一次、各拿到一行 JSON。每个账号必须用不同设备号（不同机器），这是服务端的限制。

四、第二步：上传表格，把账号填进去

1. 上传表格模板

项目里给你备好了一张现成的表格模板 Trae签到-金山文档空表格.xlsx，表头、列宽都已经调好，直接用它，不用自己新建。

打开微信上的金山文档小程序，把这张表格上传进去。

2. 填账号

上传后表头已经齐了，从第 2 行开始，每行填一个账号：

列 表头 怎么填
A 账号（JSON） 粘第一步拿到的那一整行 JSON
B 是否签到 填「是」才签，其它/留空都跳过
C Server酱 token 要推送就填，不要就留空
D PushPlus token 同上
E 企业微信 key 群机器人 webhook 的 key 或完整地址，同上
F 签到结果 不用管，脚本会自己写

关于推送（可选）： C / D / E 三列你填哪列就推哪列，也能同时填多个。都不填也能正常签到，只是不通知你。

  • Server酱：在 https://sct.ftqq.com 用微信扫码，拿到一个 SCT... 开头的 token；
  • PushPlus：在 https://www.pushplus.plus 拿到 token；
  • 企业微信：在群聊添加「群机器人」，得到 Webhook 地址（填完整地址或地址里 key= 后面的那串都行）。

五、第三步：粘贴脚本，设定时任务

这是最后一步，把「签到脚本」交给金山文档自动跑。

1. 打开脚本编辑器

在金山文档表格里：顶部菜单「效率」→「高级开发」→「AirScript 脚本编辑器」。

2. 粘贴脚本

新建一个脚本，把项目里的 Trae签到-金山文档AirScript.js 整个内容复制粘贴进去，保存。

脚本开头那几个 dengdai、renwu 是调「延迟」和「抽签」的，新手不用动；账号行数脚本会自动识别，也不用填。

3.添加服务

4. 建定时任务

在脚本编辑器里点「定时任务」（或「计划任务」），新建一个：

  • 设置为每天运行；
  • 时间避开整点，比如 08:37 这种随机一点的时刻。

截图位置：这里放一张「新建定时任务、选每天、设时间」的图。

保存后，到点它就会自己跑了。

六、验证一下有没有配好

  1. 可以在脚本编辑器里点「运行」手动跑一次，看下方日志；

  2. 如果签到成功，表格 F 列会写上「xx-xx已签到」；

  3. 填了推送的话，你的微信 / 企业微信会收到一条「签到成功」的消息。

看到这些，就说明整套已经跑通了，以后每天全自动，不用再管。

七、常见问题

Q1：运行 python 提示「不是内部或外部命令」 说明 Python 没装好，或者装的时候没勾 Add Python to PATH。重新装一遍勾上，或重启命令行再试。

Q2：浏览器登录后地址栏没跳到 refreshToken=... 多半是回调端口被占了（token 被别的程序接走了）。按终端提示用 netstat -ano | findstr :端口 查一下是谁占用，结束后 Ctrl+C 重跑。

Q3：签到时日志提示「风控拦截 9074」 设备号不对。设备号必须是 Trae 客户端真实注册的那串，自己编的会被拒。重新在装了 Trae 客户端的机器上跑 trae_gettoken.py 拿。

Q4：提示「鉴权失败 1001 / 1002」 你的 token 失效了。重新跑一次 trae_gettoken.py，把新的一行 JSON 填回 A 列。

Q5：某天没签上 脚本带了随机延迟和抽签，偶尔会「抽空跳过」。多建几个定时任务分摊一下即可，这是为了避开多账号同时请求被风控。

Q6：一个账号每天能签几次？ 一个设备号一天只能签一个账号。多账号必须各用各的设备号（各在一台装过客户端的机器上取）。
